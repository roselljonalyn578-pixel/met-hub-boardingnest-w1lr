# Website Group System

A Django-based website management system with a neon cyberpunk theme.

## Features
- Add and manage websites
- Neon-dark blue theme with security motifs
- Responsive design
- Admin interface

## Setup
1. Install requirements: `pip install -r requirements.txt`
2. Run migrations: `python manage.py migrate`
3. Start server: `python manage.py runserver`
